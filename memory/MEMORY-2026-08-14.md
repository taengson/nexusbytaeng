## 🔍 [리뷰어] ACP 에이전트 모델 설정 분석

### 배경
- 사용자는 ACP 에이전트(Hermes, Gemini, OpenCode)가 기본 모델만 사용하는 상황에서 답답함을 느낌.
- 각 에이전트의 모델 선택/변경 메커니즘을 조사하여 `nexusbytaeng`에 적용 방안을 모색.

### 조사 결과

#### 1. CLI 인자로 시작 시 모델 지정 가능
| 에이전트 | 명령어 예시 |
|---|---|
| OpenCode | `opencode acp -m openai/gpt-4o` |
| Gemini | `gemini --acp -m gemini-2.5-pro` |
| Hermes | `hermes acp -m claude-sonnet-4-20250514` |

#### 2. ACP 연결 전 모델 목록 조회
| 에이전트 | 명령어 | 결과 | 자동화 가능 여부 |
|---|---|---|---|
| OpenCode | `opencode models` | ✅ `provider/model` 한 줄씩 출력 | 가능 |
| Gemini | `gemini models` | ❌ TUI 대화형 모드로 진입, 검색어로 처리 | 불가 |
| Hermes | `hermes model` | ❌ 대화형 provider/model 설정 마법사 | 불가 |

#### 3. ACP 연결 후 `/model` slash command 전달 실험
| 에이전트 | `/model` 또는 `/models` 입력 | 반응 |
|---|---|---|
| Hermes | `/model` | ✅ "Current model: Nemotron-3.5-Lightning / Provider: custom" 출력 |
| Gemini | `/models` | ❌ 반응 없음 (일반 텍스트로 처리 또는 무시) |
| OpenCode | `/models`, `/model` | ❌ 반응 없음 |

### 핵심 인사이트
- ACP `session/prompt`로 전송된 `/model` 텍스트는 **에이전트가 내부적으로 slash command로 인식할 때만 동작**.
- Hermes는 내부 slash command 인터프리터가 ACP 모드에서도 동작.
- Gemini/OpenCode는 ACP 모드에서 내부 slash command를 처리하지 않는 것으로 보임.
- 따라서 **통일된 `/model` 명령으로 모든 에이전트의 모델을 제어하는 것은 현재 불가능**.

### 적용 방향

#### 결정: 시작 시 모델 선택 + 세션 재시작 방식의 모델 변경
- ACP 연결 시작 시 모델을 지정.
- 모델 변경이 필요하면 현재 ACP 세션을 종료하고 새 모델로 새 세션 시작.
- 런타임 slash command(`/model` 등)는 구현하지 않음.

#### 이유
- ACP 에이전트 서버는 세션 생성 시 모델과 내부 상태를 초기화.
- 런타임 모델 변경은 에이전트별 동작이 불확실하고 상태 일관성이 깨질 위험.
- 세션 재시작은 모든 에이전트에서 동일하고 예측 가능한 동작을 보장.

#### 구성 요소
1. **에이전트 설정 파일** (프로젝트 내부)
   - `config/agents.yaml.example`: 저장소에 포함된 템플릿. 에이전트별 기본 모델, 사용 가능한 모델 목록, 모델 플래그 정의.
   - `config/agents.yaml`: 개발/실행 시 사용. `.gitignore`에 추가하여 사용자별 설정이 저장소에 올라가지 않도록 관리.
   - OpenCode는 `opencode models`로 동적 목록 조회 가능.
   - Gemini/Hermes는 정적 모델 목록 사용.

2. **시작 시 모델 선택 UI**
   - `HomeScreen` 또는 별도 모달에서 에이전트 선택 후 모델 선택.
   - 선택한 모델을 ACP 실행 명령어 인자(`-m <model>`)로 전달.

3. **세션 재시작 메커니즘** (향후 필요 시)
   - `SessionWorkspace`에 현재 세션 종료 후 새 모델로 재시작하는 기능.
   - 맥락 유지가 필요하면 이전 세션 요약을 시스템 메시지로 주입.

#### Step 2: 설정 로더 구현
`src/core/agent_config.py`:

```python
import yaml
from pathlib import Path
from typing import Dict, List, Optional

class AgentConfig:
    def __init__(self, config_path: Path):
        self.config_path = config_path
        self.data = self._load()

    def _load(self) -> dict:
        if not self.config_path.exists():
            return {"agents": {}}
        with open(self.config_path) as f:
            return yaml.safe_load(f) or {"agents": {}}

    def get_agent(self, mode: str) -> dict:
        return self.data.get("agents", {}).get(mode, {})

    def get_command(self, mode: str, model: Optional[str] = None) -> List[str]:
        agent = self.get_agent(mode)
        command = list(agent.get("command", []))
        model_flag = agent.get("model_flag", "-m")
        selected_model = model or agent.get("default_model")
        if selected_model:
            command.extend([model_flag, selected_model])
        return command

    def get_models(self, mode: str) -> List[str]:
        agent = self.get_agent(mode)
        return list(agent.get("models", []))
```
