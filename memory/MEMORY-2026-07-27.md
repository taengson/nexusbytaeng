**`hermes chat`가 디폴트로 `--tui` 모드를 실행** → 서브프로세스가 자체 Textual TUI를 띄우고 stdin/stdout을 독점하므로 raw text가 파이프에 출력되지 않음.

```python
self.process = await asyncio.create_subprocess_shell(

    stdin=PIPE, stdout=PIPE, stderr=PIPE,
)
```

`--cli`가 `prompt_toolkit` REPL로 강제 → plain text stdout 출력.

**실패 이유 요약**:
- 7/21 PTY: 불필요한 시도 (원인 misdiagnosis)

#### 🔴 P0 — 메시지가 스택처럼 쌓이지 않고 덮어씀 (가장 시급)

**문제**: `session_workspace.py`의 `update_last_ai_message()`가 항상 마지막 AI 위젯을 찾아 텍스트를 이어붙임. 두 번째 질문의 응답이 첫 번째 응답 위젯에 섞여 들어감.

**원인 코드** (`session_workspace.py`):
```python
def update_last_ai_message(self, text: str):
    message_list = self.query_one("#message-list", VerticalScroll)
    widgets = message_list.children
    for w in reversed(widgets):
        if isinstance(w, MessageWidget) and w.sender == "ai":
            last_ai_widget = w
            break
    if last_ai_widget:
        last_ai_widget.append_text(text + " ")
```

- `_active_ai_widget` 인스턴스 변수로 현재 스트리밍 중인 위젯 추적

- `update_last_ai_message()`가 `_active_ai_widget`에 직접 텍스트 추가
