# Development Memory Notes

## 📚 Legacy Project Reference (`examples/private_space`)
- **Core Modules**: 
  - `src/llm_chat/core.py`: Multi-provider LLM logic using `litellm`.
  - `src/web_socket/`: Server (separate process, `0.0.0.0` binding) and Client.
  - `src/utils/logger.py`: `LogManager` for markdown-based session logging with `--- Session Started ---` markers.
- **UI/UX Patterns**:
  - **Layout**: Dynamic switching via CSS `display: none/block` to prevent `MountError`.
  - **Theme**: Retro style (Deep Navy background, solid borders, specific bubble colors).
  - **Network Chat**: Left-aligned (Self) vs Right-aligned (Other) messages.
  - **Commands**: Dual support for English/Korean commands (e.g., `/clear` / `/지우기`).
- **Key Features**:
  - **Forwarding (Toss)**: `/forward` / `/전달` with contextual formatting (Question $\rightarrow$ Answer) and Click-to-Forward Modal.
  - **Diagnostics**: `/test` / `/테스트` using `curl -v` for AI server reachability.
  - **Resilience**: `llm_timeout` in `config.json` to prevent app hangs.

## 🚀 NexusByTaeng Goals
- **Architecture**: Re-implement `toad` pattern: `SideBar` $\rightarrow$ `MainScreen` $\rightarrow$ `Conversation` $\rightarrow$ `MessageWidgets`.
- **Multi-Agent**: Transition from single config to `AgentRegistry` for dynamic agent switching.
- **Modern TUI**: Professional dark theme using `.tcss` and standard Textual variables; card-based message bubbles.
- **License**: Reference-based implementation (mimic UX/UI) to avoid AGPL-3.0 contamination.

## ⚠️ Critical Reminders
- **Stability**: Always use timeouts for network calls; avoid repeated mounting of widgets.
- **Network**: Ensure WebSocket server handles external binding and clean termination (PID tracking).
- **Logic**: Keep UI and business logic strictly decoupled.
