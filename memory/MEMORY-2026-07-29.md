### 🔴 근본 원인
`session_workspace.py`의 `on_input_result`에서 **`HERMES_ACP` 모드만 체크**하여 Gemini ACP 프롬프트가 전송되지 않음.

```python
# 수정 전
if self.current_mode == ConnectionMode.HERMES_ACP and ...:

# 수정 후
if self.current_mode in (ConnectionMode.HERMES_ACP, ConnectionMode.GEMINI_ACP) and ...:
```
